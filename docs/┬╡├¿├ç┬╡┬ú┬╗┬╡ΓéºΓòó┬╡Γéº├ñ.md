# 链网E判技术架构

## 主链路

1. 输入解析：企业名称、股票代码、统一社会信用代码。
2. 主体锁定：上市公司优先读取证券结构化档案；信用代码必须完成代码—企业名称同源核验。
3. Tavily五主题并行Search：工商档案、年度报告、股权投资、关联交易担保、司法合规。
4. Tavily三路定向Extract：企业档案、关系网络、风险事件。
5. DeepSeek V4 Flash三通道并行抽取。
6. Python完成证据校验、冲突处理、风险评分、SHAP、ROI和多跳图谱。
7. DeepSeek V4 Pro只读取紧凑结构化风险包，生成风险—影响—建议一一对应的决策项。

## 主体保护

- 股票代码锁定上市发行人，公告中出现的子公司、供应商、客户和担保对象不能覆盖核心主体。
- 证券简称可从官方披露升级为法定公司全称。
- 每个字段、关系和风险事件必须绑定来源编号。
